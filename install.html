CineRecreate AI · Android install

Put the app on your phone.

Install CineRecreate as a home-screen web app. It opens like an app and keeps the interface available offline. This is the existing web app—not a native APK and not an offline AI video generator.

Checking install options…

On Android, use your browser menu to install it:

  1. Tap the browser menu ⋮.
  2. Choose Install app or Add to Home screen.
  3. Confirm the prompt.

If you are viewing this inside another app, open the page in Chrome or Samsung Internet first.

AI video generation needs the separately configured online service. Installing the web app does not download an AI model or create an APK.
